# 더로직 영어학원 홈페이지

HTML, CSS, JavaScript로 만든 더로직 영어학원 홈페이지입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 내용 (학원 소개, 프로그램, 강사진, 오시는 길 등) |
| `style.css` | 디자인 (색상, 글꼴, 배치) |
| `script.js` | 동작 (모바일 메뉴, 스크롤 애니메이션) |

## 보는 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 볼 수 있어요.

## 꼭 채워야 할 내용

`index.html`에서 `○○○`, `000-0000-0000`, `00:00` 같은 자리 표시를 실제 정보로 바꿔 주세요.

- 전화번호: `tel:`·`sms:` 링크 안의 번호까지 모두 바꿔야 버튼이 동작해요.
- 주소, 운영 시간, 주차 안내
- 프로그램별 대상 학년과 수업 내용
- 강사진 이름, 약력, 담당 (사진을 쓰려면 `teacher__photo` 안의 이모지를 `<img>`로 바꿔요)
- 푸터의 대표자명, 학원등록번호, 사업자등록번호

## 지도 넣기

카카오맵이나 네이버 지도에서 학원 위치를 찾은 뒤 **공유 → 지도 퍼가기(HTML 태그)** 코드를 복사해서
`index.html`의 `<div class="map ...">` 안에 있는 `<span>🗺️ 지도 영역</span>` 대신 붙여 넣으세요.

## 색상 바꾸기

`style.css` 맨 위에서 `--navy`(메인 색)와 `--accent`(포인트 색) 값을 바꾸면 전체 색이 바뀌어요.

## 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub 저장소의 **Settings → Pages**로 이동해요.
2. **Source**를 `Deploy from a branch`로, 브랜치와 `/ (root)` 폴더를 고르고 저장해요.
3. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속할 수 있어요.
