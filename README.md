# 더로직 고등영어 홈페이지

HTML, CSS, JavaScript로 만든 더로직 고등영어(동탄) 홈페이지입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 내용 (1학기 결과, 학원 소식, 수업 안내, 오시는 길) |
| `style.css` | 디자인 (색상, 글꼴, 배치) |
| `script.js` | 하단 연도 자동 표시 |

## 보는 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 볼 수 있어요.

## 아직 채워야 할 내용

`index.html`에서 다음 정보가 생기면 채워 주세요. 푸터의 대표자·등록번호 줄은 주석으로 숨겨 두었어요.

- 운영 마감 시간과 휴무일
- 푸터의 대표자명, 학원등록번호, 사업자등록번호
- 새 블로그 글이 올라오면 "학원 소식" 목록에 추가
- 새 학기 결과가 나오면 첫 화면 문구 업데이트

## 지도 넣기

카카오맵이나 네이버 지도에서 학원 위치를 찾은 뒤 **공유 → 지도 퍼가기(HTML 태그)** 코드를 복사해서
`index.html`의 `<a class="map ...">` 부분을 `<div class="map">퍼가기 코드</div>`로 바꿔 넣으세요.

## 색상 바꾸기

`style.css` 맨 위에서 `--ink`(글자·버튼 색)와 `--point`(강조색) 값을 바꾸면 전체 색이 바뀌어요.

## 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub 저장소의 **Settings → Pages**로 이동해요.
2. **Source**를 `Deploy from a branch`로, 브랜치와 `/ (root)` 폴더를 고르고 저장해요.
3. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속할 수 있어요.
